# Project workflow

- Use Codex for this project; do not create Claude Code configuration files.
- After substantial requested changes, run appropriate validation, commit the changes, and push to GitHub automatically so the owner can test through GitHub Pages. The owner has authorized this workflow; do not ask for confirmation again.
- Use normal pushes. Never force-push or overwrite unrelated work as part of this workflow.
- Report the pushed commit and deployment status. Do not claim the live site is updated until deployment is verified.
